# 🏢 Sistema de Gestão de Condomínio

Este é um sistema web focado na administração e organização de condomínios residenciais. O projeto reúne diversas interfaces para facilitar o controle de moradores, reservas de áreas comuns, gerenciamento de usuários e acompanhamento de ocorrências.

## 🚀 Demonstração

O projeto está hospedado e pode ser acessado diretamente pelo navegador através do link:
👉 [Acessar o Sistema de Condomínio](https://kevintav2025.github.io/SistemaCondominio/)

---

## 💻 Telas Integradas

O sistema é composto pelas seguintes interfaces (conectadas através da página principal):

* **Página Inicial (`index.html`):** Painel central e menu de navegação do sistema.
* **Autenticação (`login.html`):** Tela de login para acesso seguro dos usuários.
* **Painéis de Controle (`dashboard.html` / `dashboardv2.html`):** Gráficos e resumos visuais dos dados do condomínio.
* **Cadastro de Moradores (`telaMorador.html`):** Gerenciamento e listagem de residentes.
* **Controle de Usuários (`telaUsuario.html`):** Administração de contas de operadores e síndicos.
* **Dados do Condomínio (`condominio.html`):** Informações gerais sobre a estrutura do local.
* **Apartamentos (`telaapartamento.html`):** Mapeamento e bloco de unidades habitacionais.
* **Reservas (`reservas.html`):** Controle de agendamentos de espaços.
* **Áreas Comuns (`areacomum.html`):** Cadastro e regras dos espaços coletivos (salão de festas, churrasqueira, etc).
* **Ocorrências (`telaOcorrencia.html`):** Registro de reclamações, sugestões ou incidentes.
* **Perfil do Usuário (`telaperfil.html`):** Página de dados pessoais do usuário logado.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação das páginas e formulários.
* **CSS3:** Estilização visual, layout responsivo e interface do usuário.
* **C#:** Arquivos de backend/lógica associados ao sistema.
